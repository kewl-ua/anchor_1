# Anchor RTS

Изометрическая компететив RTS в духе Age of Empires II, война около 2004 года. C++20 + raylib 6.0, детерминированный lockstep.

Дизайн игры и план работ: [docs/DESIGN.md](docs/DESIGN.md).

## Сборка

Нужны Visual Studio Build Tools (MSVC) и CMake. raylib скачивается автоматически.

```
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release
build\bin\Release\anchor.exe
```

`anchor.exe --smoke-test shot.png`: армия атакует вражескую базу на ускоренном времени, в конце снимается скриншот и выводятся тик, контрольная сумма и число выживших. Работает и вместе с `--host` / `--join`: так проверяется, что обе стороны посчитали бой одинаково. `--look x,y` держит камеру над тайлом (x, y), чтобы снять конкретное место карты; `--ticks n` снимает кадр на тике n; `--scene garrison` — вместо атаки пехота занимает ближайший дом, а танки рушат соседний; `--scene economy` — тыловики рубят лес, штаб нанимает; `--scene build` — тыловики строят казарму и склад; `--scene logistics` — склады у станции, две фуры и первый поезд (снимайте после 1200-го тика); `--scene recon` — разведчики встают на НП; `--scene skills` — танки заряжают бронебойный и бьют по области, БМП чешет фронт пулемётом; `--scene works` — стрелки копают траншею и окопы; `--scene supply` — (только офлайн) танки почти без топлива, БМП без выстрелов, к ним едут бензовоз и машина с БК; `--scene artillery` — (только офлайн) гаубица, миномёт, АГС, РСЗО и танк с закрытых позиций бьют по местности впереди, разведчик на НП; `--scene engineering` — (только офлайн) сапёры ставят колючку, ежи, ДЗОТ и мину; `--scene signals` — (только офлайн) две станции РЭР засекают вражеские КШМ и танк, наши танки уходят в радиомолчание, одному приказ идёт посыльным (снимайте до 60-го тика, пока посыльный в пути); `--scene air` — (только офлайн) два Су-25 с аэродрома за базой идут на задание туда, где ждут ПЗРК, «Шилка» и РЛС противника (снимайте около 150-го тика); `--scene trucks` — (только офлайн) у станции склад и склад б/п, три фуры: на еде, закреплённая за складом б/п и на «авто»; `--scene forward` — (только офлайн) ближний амбар уже склад б/п, к нему едет машина с БК, в другом тыловики делают склад ГСМ. `--scene timber` — (только офлайн) тыловики рубят опушку, у неё стоит фура; `--zoom n` — масштаб камеры в процентах (30–250) для снимка. `--reveal` снимает туман войны с экрана (только отображение, игра идёт по своим правилам).

Размер карты как в AoE II: `--map tiny|small|medium|normal|large|giant` (120–240 тайлов, по умолчанию normal 200) или число тайлов.

## Игра по сети (1 на 1)

```
anchor.exe --host              # хост, порт 7777 (или --host 9000); --map задаёт размер карты
anchor.exe --join 192.168.1.5  # клиент (или --join 1.2.3.4:9000); размер карты берётся у хоста
```

Хост играет за синих, клиент за красных. Для игры через интернет хосту нужно открыть UDP-порт на роутере и разрешить `anchor.exe` в брандмауэре Windows.

Обе стороны пишут контрольную сумму состояния в правый верхний угол. При рассинхроне HUD покажет `DESYNC at tick N`.

## Архитектура

```
src/
  engine/   симуляция: карта (высоты, местность), поиск пути, юниты, оружие, снаряды, команды.
            Без графики и без float. Характеристики юнитов — таблица в unit_types.cpp,
            проходимость местности — таблица в terrain.h.
  net/      lockstep и сетевой протокол; ENet спрятан в enet_session.cpp.
  render/   графика мира: изометрия (iso.h), камера, юниты, эффекты. Читает engine, но не меняет его.
  hud/      экранный интерфейс: панели, выделение, статус сети. Читает engine, не меняет его.
  theme/    общие цвета для render и hud.
  app/      окно, лобби, главный цикл, ввод игрока -> команды.
tests/      тесты движка и сети, без окна и без сокетов.
```

Зависимости идут только вниз: `app -> net, render, hud -> engine`. render, hud и net друг о друге не знают.

Путь команды: `PlayerController` → `Lockstep::submit` → (по сети всем игрокам) → `Simulation::schedule` на тик `T + задержка` → `World::apply`.

### Правила engine (на них держится мультиплеер)

1. **Состояние меняется только через `Command`.** Ввод, HUD и сеть создают команды, а `Simulation` применяет их на нужном тике.
2. **Никакого float/double.** Вся математика на `Fixed` (Q16.16), случайность только через `engine::Rng` с общим seed.
3. **Никакого raylib, времени и `unordered_*`.** Модуль `engine` не линкуется с raylib, а тест `engine_purity` следит за остальным.
4. **Фиксированный тик**: 20 тиков/с (`Simulation::kTicksPerSecond`). Рендер интерполирует позиции между тиками, поэтому картинка плавная при любом FPS.
5. **Lockstep**: тик T выполняется, только когда пришёл ввод на него от всех игроков (пустой ввод тоже отправляется). Команда выполняется через задержку ввода: 3 тика (150 мс) по сети, 1 тик офлайн. За это время она успевает дойти до соперника. Одиночная игра идёт через тот же `Lockstep`, просто без транспорта.
6. **Проверка синхронизации**: вместе с вводом каждый пир отправляет `World::checksum()`, получатель сравнивает её со своей.
7. **Недоверие к сети**: ID игрока берётся из соединения, а не из пакета; битые, повторные и «невозможные» пакеты отбрасываются.

## Управление

| | |
|---|---|
| ЛКМ / рамка | выделить |
| Shift + ЛКМ | добавить/убрать из выделения |
| ПКМ по земле | идти (враги игнорируются) |
| ПКМ по врагу | атаковать (врагов в тумане не видно и не выбрать) |
| ПКМ пехотой по дому или блиндажу | занять (дом до 6, блиндаж до 8, пятиэтажка до 12, сотовая вышка — 1); занятый противником — обстрелять |
| ПКМ фурой по лесу / камню | встать у опушки: тыловики сдают вязанки в кузов, фура возит по 40 в штаб или на склад и возвращается |
| ПКМ тыловиками по лесу / камню (или R «Gather», затем ЛКМ) | рубить / колоть и самим носить в штаб или на склад; кончился тайл — берутся за соседний |
| Подсказка у курсора | что сделает ПКМ по тому, что под курсором (рубить лес, возить топливо на этот склад, закрепить за танком, занять дом...). Клик по крыше здания или кроне дерева — это клик по нему |
| ПКМ фурами по своему складу | закрепить за ним: возят его груз и именно туда |
| ПКМ фурами по станции | обратно на маршрут с прежним назначением |
| Фура: Q W E R | что возить: авто (что копится) / еда / б/п / топливо — на ближайший склад для груза |
| «.» или кнопка Idle вверху | следующий тыловик или фура без дела (камера к нему) |
| ПКМ тыловиками по недострою | помочь строить |
| **Сетка команд** | хоткей — это клетка сетки, как grid-раскладка в AoE II: `Q W E R T` / `A S D F G` / `Z X C V B` |
| A / S / G | атака с движением / стоп / огонь по точке (A и G — затем ЛКМ; Shift — несколько точек; ПКМ или Esc — отмена) |
| Здание: Q W E R | нанять (выделить здание — ЛКМ по нему; фуры — в штабе) |
| Тыловики: Q, W, E | Q — меню строительства (казармы пехоты, бронетехники, разведки, артиллерии, инженерная, связи, ПВО, аэродром, склады; Shift — несколько), W — переучить в стрелков, E — занять просторное здание в селе (амбар) под склад / склад б/п / склад ГСМ, затем ЛКМ по нему |
| Разведчики: Q, затем ЛКМ | встать на НП и наблюдать сектор в ту сторону (огонь не открывают) |
| Танк: Q, W | Q — выстрел по области (один ОФ-снаряд с широким разрывом), W — сменить снаряд: ОФ ⇄ бронебойный (через перезарядку) |
| БМП: Q, W | Q — пулемёт по фронту (задаёшь направление, не цель), W — граната по области (навесом, через укрытия) |
| Стрелки: Q, W, E | Q — траншея (зажать ЛКМ и протянуть линию), W — окоп на месте, E — бруствер (ЛКМ — куда смотрит) |
| Штурмовик: Q, затем ЛКМ | граната: в окоп, в траншею, в дом или блиндаж |
| Окоп (ЛКМ по нему): Q | улучшить до блиндажа (копают стоящие в окопе) |
| Сапёр: Q W E R T / Z X | мина ПП / мина ПТ / разминировать вокруг точки / колючка линией / ежи линией; ДЗОТ амбразурой в сторону ЛКМ / подрывной заряд по постройке |
| Дом или блиндаж со своими: Q | всем выйти |
| Орудия (миномёт, гаубица, САУ, РСЗО): Q, G | Q — развернуть / свернуть (и само по приказу); G, затем ЛКМ — огонь по точке, в том числе вслепую в туман; ПКМ по видимому врагу — огонь по нему. Сами не стреляют |
| Гаубица, САУ: W, E / миномёт: W | капонир / маскировка; миномёт — закрытая позиция |
| АГС: Q / РСЗО: W / танк: E, R | беглый огонь по фронту / залп по точке / огонь с закрытых позиций (−1% HP за выстрел); R — дымы (после исследования) |
| Здание: Z X C V B | исследования этого здания (склад б/п, станция, казарма разведки, казарма пехоты) |
| Рация: танк T, БМП E, миномёт E, РСЗО E, гаубица и САУ R, связист и КШМ Q | радиомолчание ⇄ эфир. В молчании станции РЭР противника не пеленгуют, но приказы доходят посыльным через 3 с, если рядом нет ретранслятора (свой штаб 12 тайлов, КШМ 12, связист 6) |
| Станция РЭР: Q | развернуть / свернуть: пеленги на рации противника в 35 тайлах; пеленги двух станций под углом от 20° дают засечку — противник виден |
| Су-25 (на полосе): G, затем ЛКМ / ПКМ по врагу | боевое задание: удар по точке / по видимому врагу. Одно задание — один вылет: взлёт, залп НАР, возврат, перевооружение со склада. В воздухе задание не меняется |
| ПЗРК, «Шилка» | сами бьют по самолётам противника в зоне досягаемости (ПЗРК — только по ним); «Шилка»: E — радар (выключенный — вдвое хуже по самолётам) |
| РЛС ПВО: Q, W | развернуть / свернуть; радар в эфире / выключить. Видит самолёты противника в 45 тайлах |
| Бензовоз / машина с БК: Q или ПКМ по складу ГСМ / б/п | заправиться на складе из запаса; стоя рядом с техникой (до 4 тайлов), сами заправляют и пополняют боекомплект |
| Бензовоз / машина с БК: W «Rail run» или ПКМ по станции | возить свой груз (топливо / б/п) со станции на ближайший склад для него, целой цистерной или кузовом |
| Машина с БК: ПКМ по своей позиции (траншея, окоп, блиндаж, ДЗОТ, капонир) | держать на ней запас б/п: возит со склада, пока не заполнит, потом докладывает. Свои в 3 тайлах и внутри берут из него сами |
| Бензовоз / машина с БК: ПКМ по своему танку, орудию, БМП | закрепить за ним: ходит следом, пополняет, пустой сам едет на склад и возвращается; S — открепить |
| Танк, БМП, орудия, «Шилка», КШМ: кнопка «Supply» | вызов по радио: едет ближайший свободный бензовоз / машина с БК с грузом (что нужно), пополняет и снова свободен. В радиомолчании без ретранслятора — не слышно |
| F2 | выделить всю армию (без тыловиков и фур) |
| Пробел | камера к выделенным |
| ЛКМ по миникарте | перенести камеру (можно тянуть) |
| ПКМ по миникарте | отправить выделенных туда |
| Стрелки / край экрана / СКМ | камера |
| Колесо | зум |
| F10 | выход |
