# Anchor RTS

Изометрическая компететив RTS в духе Age of Empires II, война около 2004 года. C++20 + raylib 6.0, детерминированный lockstep.

Дизайн игры и план работ: [docs/DESIGN.md](docs/DESIGN.md).

## Сборка

Нужны Visual Studio Build Tools (MSVC) и CMake. raylib скачивается автоматически.

```
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release
build\bin\Release\anchor.exe
```

`anchor.exe --smoke-test shot.png`: армия атакует вражескую базу на ускоренном времени, в конце снимается скриншот и выводятся тик, контрольная сумма и число выживших. Работает и вместе с `--host` / `--join`: так проверяется, что обе стороны посчитали бой одинаково. `--look x,y` держит камеру над тайлом (x, y), чтобы снять конкретное место карты; `--ticks n` снимает кадр на тике n; `--scene garrison` — вместо атаки пехота занимает ближайший дом, а танки рушат соседний; `--scene economy` — тыловики рубят лес, штаб нанимает.

Размер карты как в AoE II: `--map tiny|small|medium|normal|large|giant` (120–240 тайлов, по умолчанию normal 200) или число тайлов.

## Игра по сети (1 на 1)

```
anchor.exe --host              # хост, порт 7777 (или --host 9000); --map задаёт размер карты
anchor.exe --join 192.168.1.5  # клиент (или --join 1.2.3.4:9000); размер карты берётся у хоста
```

Хост играет за синих, клиент за красных. Для игры через интернет хосту нужно открыть UDP-порт на роутере и разрешить `anchor.exe` в брандмауэре Windows.

Обе стороны пишут контрольную сумму состояния в правый верхний угол. При рассинхроне HUD покажет `DESYNC at tick N`.

## Архитектура

```
src/
  engine/   симуляция: карта (высоты, местность), поиск пути, юниты, оружие, снаряды, команды.
            Без графики и без float. Характеристики юнитов — таблица в unit_types.cpp,
            проходимость местности — таблица в terrain.h.
  net/      lockstep и сетевой протокол; ENet спрятан в enet_session.cpp.
  render/   графика мира: изометрия (iso.h), камера, юниты, эффекты. Читает engine, но не меняет его.
  hud/      экранный интерфейс: панели, выделение, статус сети. Читает engine, не меняет его.
  theme/    общие цвета для render и hud.
  app/      окно, лобби, главный цикл, ввод игрока -> команды.
tests/      тесты движка и сети, без окна и без сокетов.
```

Зависимости идут только вниз: `app -> net, render, hud -> engine`. render, hud и net друг о друге не знают.

Путь команды: `PlayerController` → `Lockstep::submit` → (по сети всем игрокам) → `Simulation::schedule` на тик `T + задержка` → `World::apply`.

### Правила engine (на них держится мультиплеер)

1. **Состояние меняется только через `Command`.** Ввод, HUD и сеть создают команды, а `Simulation` применяет их на нужном тике.
2. **Никакого float/double.** Вся математика на `Fixed` (Q16.16), случайность только через `engine::Rng` с общим seed.
3. **Никакого raylib, времени и `unordered_*`.** Модуль `engine` не линкуется с raylib, а тест `engine_purity` следит за остальным.
4. **Фиксированный тик**: 20 тиков/с (`Simulation::kTicksPerSecond`). Рендер интерполирует позиции между тиками, поэтому картинка плавная при любом FPS.
5. **Lockstep**: тик T выполняется, только когда пришёл ввод на него от всех игроков (пустой ввод тоже отправляется). Команда выполняется через задержку ввода: 3 тика (150 мс) по сети, 1 тик офлайн. За это время она успевает дойти до соперника. Одиночная игра идёт через тот же `Lockstep`, просто без транспорта.
6. **Проверка синхронизации**: вместе с вводом каждый пир отправляет `World::checksum()`, получатель сравнивает её со своей.
7. **Недоверие к сети**: ID игрока берётся из соединения, а не из пакета; битые, повторные и «невозможные» пакеты отбрасываются.

## Управление

| | |
|---|---|
| ЛКМ / рамка | выделить |
| Shift + ЛКМ | добавить/убрать из выделения |
| ПКМ по земле | идти (враги игнорируются) |
| ПКМ по врагу | атаковать |
| ПКМ пехотой по дому | занять дом (до 6 бойцов); дом противника — обстрелять |
| ПКМ тыловиками по лесу / камню | рубить / колоть, носить в штаб |
| ЛКМ по своему штабу | выделить штаб; Q — нанять тыловика |
| R | выделенные тыловики идут переучиваться в стрелков |
| A, затем ЛКМ | атака с движением (Shift — несколько точек; ПКМ или Esc — отмена) |
| G, затем ЛКМ | огонь по точке (по посадке, по дому) |
| S | стоп |
| F2 | выделить всю армию (без тыловиков) |
| Пробел | камера к выделенным |
| ЛКМ по миникарте | перенести камеру (можно тянуть) |
| ПКМ по миникарте | отправить выделенных туда |
| Стрелки / край экрана / СКМ | камера |
| Колесо | зум |
| F10 | выход |
